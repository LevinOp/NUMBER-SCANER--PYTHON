# 🔢 Number Scanner

A simple, interactive Python project that scans a range of numbers and identifies different number properties.

## 📌 About the Project

Number Scanner is a beginner-level Python project created to practice fundamental programming concepts such as:

- Variables
- User input (`input()`)
- Conditional statements (`if`, `elif`)
- For loops
- Nested loops
- Counters
- Modulo operator (`%`)

## ✨ Features

The program provides four scanning options:

1. **Even Numbers** – Counts and displays even numbers within a given range.
2. **Odd Numbers** – Counts and displays odd numbers within a given range.
3. **Prime Numbers** – Identifies and counts prime numbers within a given range.
4. **Divisible by 5** – Finds and counts numbers divisible by 5.

## 🛠️ Technologies Used

- Python 3
- Built-in Python functions and operators

## 🚀 How to Run

1. Download or clone this repository.
2. Open the project folder.
3. Run the Python file using your terminal.

```bash
python number_scanner.py
```
